GammaOS Next (LineageOS 21 / Android 14) для карманной консоли **AISLPC RG52 Mini**
на Rockchip RK3562. Здесь перечислено то, что изменилось после
[v1.8](release-v1.8.md).

## Что нового

### Растягивание раздела данных ищет его по имени

При первой загрузке раздел данных растягивается на всю карту. Раньше скрипт
искал его по номеру (девятый раздел карты), теперь — по имени `userdata`. Если
за ним на карте лежит ещё какой-то раздел, растягивание пропускается. Нужно для
общей карты dArkOS + GammaOS, на обычной карте ничего не меняется.

### Флаги для меню выбора системы на общей карте

На загрузочный раздел теперь кладутся два файла для меню выбора системы на
общей карте dArkOS + GammaOS. Пока мастер настройки не завершён (нет папок
ROMs), меню не показывается и карта грузит GammaOS. Пункт загрузки с
внутренней памяти следует за переключателем «Allow reboot to eMMC» в GammaOS
Toolbox. Файлы сверяются на каждой загрузке и переживают обновление по
воздуху. На обычной карте ни на что не влияют.

### Загрузчик с меню выбора системы

Новый загрузчик u-boot (основная линия u-boot-rg52, `next-dev-g0ea01de2e9`)
умеет показывать меню выбора системы на общей карте dArkOS + GammaOS: GammaOS,
dArkOS и, если включён переключатель «Allow reboot to eMMC», внутренняя память.
Меню включается, только когда на карте есть обе системы. На обычной карте
GammaOS загрузка идёт как раньше, без меню.

Разгон и всё остальное, кроме самого u-boot, не изменились: таблицы частот
BL31, OP-TEE и dtb загрузчика побайтно те же, что в прежнем `uboot-1.3-oc`.
«Reboot to eMMC» работает как раньше. Обновление по воздуху записывает новый
загрузчик вместе с остальными разделами.

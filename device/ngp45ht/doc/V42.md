# V42（2026-11-07）

基线 V41；只改 p5 vendor + 首启脚本，不碰 system/userdata。

## 集成内容

- **LANGOS 3.7.1**（versionCode 24）：3DS 选择器加入 **Azahar(官方)**（content URI 直接传 ROM）；
  PS2 选择器支持 **ARMSX2**（绝对路径 data 直接启动指定 ROM）。
- **官方 Azahar 2126.2 vanilla**：随镜像预置，首启 `pm install` 到 `/data/app`（可卸载）；
  性能配置预置在 `/etc/ngp/azahar/config.ini`，首启复制到
  `/data/media/0/azahar-emu/config/config.ini`。
- **ARMSX2 2.9.2 legacy-armv8.0**：随镜像预置；必须用 legacy 包，armv8.2 在 A53 上 SIGILL。
- **手柄拼音 IME 0.1.1**：新增无障碍按键过滤，修复 LocalSend 等 Flutter 应用无法输入；
  首启 `pm install -r` 覆盖 system 里的 0.1.0，并自动启用无障碍服务。
- **V39 键位**：M=HOME，返回键=BACK，长按 1.5s 退出前台游戏。
- **HDMI 自愈**：唤醒后 HWC 把 VOP 抢回内屏时，watch 自动重做 16:9 切换。
- **EEROMS 短链接**：`ngp-eeroms-link` 开机维护 `/storage/EEROMS`；
  `ngp-fixup.sh` 首启把 LANGOS `rom_root` 改为该短路径。

## 首启注意

- 官方 Azahar 仍需完成一次向导：用户目录选 `/storage/emulated/0/azahar-emu`、
  授予文件系统权限；游戏手柄里 **Auto-Map Controller** 按一次 A，否则物理 B 会弹菜单。
- ARMSX2 需要用户自己配置 BIOS/ROM 目录。
- 官方 Azahar / ARMSX2 / NetherSX2 都装在 `/data/app`，可正常卸载；
  卸载后不会自动装回（`/data/ngp/emu-installed/<包名>` 标记）。
